# آل عابدين للإدارة الشاملة

نظام محلي عربي لإدارة محل المحمول والريسيفر والأقمار الصناعية. مستقل تمامًا عن أي نظام محافظ أو كاش أو فوري.

## التشغيل
- افتح `index.html` مباشرة في المتصفح.
- لتشغيل نسخة سطح المكتب: `npm install` ثم `npm start`.
- البناء: `npm run build:win`.

## الوحدات
لوحة التحكم، المبيعات، المشتريات، المنتجات، المخازن والجرد، العملاء، الموردون، المرتجعات، خزينة المحل، الحسابات، المصروفات والإيرادات، التقارير، والإعدادات.

## التخزين
تُحفظ البيانات محليًا في المتصفح باستخدام IndexedDB، مع تصدير واستيراد نسخة JSON احتياطية. هذه مرحلة تأسيسية قابلة للتطوير والاختبار؛ لا تعتمد عليها محاسبيًا قبل استكمال اختبارات المطابقة والتقارير.
